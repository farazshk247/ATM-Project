# ATM Client Project 

## Overview

Description: A secure, console-based/GUI application that simulates the core functionalities of a real-world Automated Teller Machine. The project enables users to interact with a banking backend, featuring user authentication for secure access. It offers a complete workflow, including creating a new account with a unique PIN, securely signing in, and performing standard transactions.
Key Features:
1. Account Creation: Allows users to register new accounts, setting a PIN and initial deposit.
2. Secure Sign-In: Authenticates users via PIN verification before allowing access.
3. Cash Deposit: Enables users to deposit funds into their account securely.
4. Cash Withdrawal: Allows users to withdraw cash, with built-in validation for sufficient balance.
5. Balance Inquiry: Real-time checking of current account balance.

## How to Run

1. Run ATMServer.java
2. Once ATMServer.java is running, run ATMClient.java.
